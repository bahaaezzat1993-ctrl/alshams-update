# برنامج الشمس - مستودع التحديثات

هذا المستودع مخصص لتوزيع تحديثات برنامج الشمس.

- `version.json`: رقم آخر إصدار ورابط التحميل، يقرأه البرنامج للتحقق من وجود تحديث.
- ملفات البرنامج (exe/zip) تُرفع في قسم Releases.

## طريقة نشر تحديث جديد

1. أنشئ Release جديد برقم الإصدار (مثل v1.0.1) وارفع ملف البرنامج.
2. عدّل `version.json` وغيّر قيمة `version` إلى الرقم الجديد.
